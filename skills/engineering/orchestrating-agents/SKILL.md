# Astra Orchestrator

Согласованная настройка распределения ролей и моделей с приоритетом качества. Явный выбор пользователя и инструкции более высокого уровня сохраняют приоритет. Настройка не меняет модель текущего чата.

Выбери роль по фактическому заданию, а не по классу модели или названию hook:

- **Worker:** если родитель поручил ограниченную задачу, прочитай [worker](references/worker.md). Продолжай назначенный одобренный этап; возвращай решения и потребность в дополнительном делегировании родителю. Координаторский справочник для такой задачи не нужен.
- **Coordinator:** если ведёшь задачу пользователя, прочитай [coordinator](references/coordinator.md) перед оценкой модели, проектированием, планированием, делегированием или исполнением Superpowers. Он содержит маршрутизацию, согласования этапов, постановку задач и проверки приёмки.

Загружай только релевантные skills и справочники. Уже одобренное задание реализации начинается с назначенного этапа, без нового brainstorming. После продолжения или сжатия восстанови решения, статус и незавершённый этап по артефактам проекта.

Standalone-установка содержит этот skill и справочники. Доверенные hooks подключает отдельный плагин Astra Orchestrator, когда включён. Отключение плагина прекращает дальнейшее обнаружение/инъекцию его skill и hooks, но не удаляет уже попавшие в transcript инструкции; для чистого контекста начни новый чат. Глобальные значения моделей настраиваются отдельно от переключателя плагина; skill не переключает модель текущего чата.
